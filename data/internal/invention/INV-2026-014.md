# 발명 신고서 INV-2026-014

- 발명의 명칭: 스캔 체인 고장 위치 예측을 위한 학습 데이터 생성 방법 및 진단 장치
- 신고 부서: 반도체 테스트팀
- 발명자: 김도윤, 한지우
- 내부 과제 코드: DFT-7Q3
- 신고일: 2026-09-14 (v1.2 — 실험 결과 갱신)

## 1. 해결하려는 문제
스캔 체인이 끊기거나 특정 스캔 셀이 0 또는 1로 고착되면, 테스트 패턴을 넣어도 출력이 한꺼번에 틀어져 어느 셀이 고장인지 알기 어렵다. 지금은 엔지니어가 고장 로그를 보며 후보 셀을 좁히는 데 칩당 평균 3.5시간이 걸린다.

## 2. 발명의 구성
1. 고장 주입 시뮬레이터: 정상 설계 넷리스트의 스캔 셀마다 고착 고장(stuck-at-0/1)과 지연 고장을 하나씩 주입해, 테스트 패턴별 출력 오류 로그를 만든다.
2. 특징 추출부: 고장 로그를 패턴 번호 × 스캔 출력 비트의 오류 행렬로 바꾸고, 첫 오류 위치·오류 비트 수·연속 오류 길이를 특징으로 뽑는다.
3. 고장 유형별 예측 모델: 고착 고장용과 지연 고장용 신경망을 따로 학습해, 입력 로그에서 고장 셀 후보를 확률 순으로 낸다.
4. 재시험 검증부: 상위 후보 셀에 맞춘 진단 패턴을 다시 넣어 실제 고장 셀인지 확인하고, 틀리면 다음 후보로 넘어간다.

## 3. 실험 결과 (테스트 칩 4종, 고장 주입 1,200건)
- 상위 3개 후보 안에 실제 고장 셀이 있는 비율: 92.4%
- 재시험 검증 후 최종 적중률: 98.1%
- 진단 시간: 칩당 평균 3.5시간 → 12분

## 4. 선행기술 조사 메모
Patent Lab으로 조사한 결과, 고장 로그로 학습 데이터를 만드는 공개 특허는 있으나 고장 유형별로 모델을 나누고 재시험으로 검증하는 구성은 찾지 못했다. 특허팀 검토 후 2026년 12월 출원을 목표로 한다.
