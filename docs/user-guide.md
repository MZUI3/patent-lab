# 사용 안내 (연구원용)

## 할 수 있는 것
| 화면 | 하는 일 |
|---|---|
| 선행기술 조사 | 아이디어를 몇 문장으로 적으면 가까운 한국 선행 특허를 찾아, 아이디어의 구성요소마다 청구항에 나와 있는지(개시·일부·미개시) 대비한다 |
| 특허 찾기 | 조건(기술·연도·출원인·등록 상태)이나 이름·번호로 특허를 찾고, 고른 특허에 질문하거나 청구항 해설을 본다 |
| 사내 문서 | 내 계정이 열람할 수 있는 사내 문서(발명 신고서·실험 보고서·실험 데이터·회의록·지침)에 질문한다 |

## 결과를 읽는 법
- **[근거 n]** 이 붙은 문장만 근거가 있는 내용이다. 펼쳐서 원문 구절을 확인한다.
- 선행기술 조사의 **개시·일부** 판정은 LLM이 인용한 구절이 청구항 원문에 실제로 있을 때만 나온다. 그래도 출원 판단 전에는 원문을 직접 읽는다.
- "제공된 문서에서 확인되지 않습니다"는 근거에 답이 없다는 뜻이다. 추측해서 채우지 않는다.
- 숫자·단위는 원문에서 다시 확인한다 (지침 GUIDE-SEC-001).

## 자료 등급과 AI 전송
| 등급 | 예 | 보낼 수 있는 곳 |
|---|---|---|
| 공개 | 공개 특허, 학회 초록, 보도자료 | 무료 등급 외부 AI까지 |
| 내부 | 실험 보고서, 회의록, 실험 데이터 | 회사가 계약한 외부 AI까지 |
| 기밀 | 출원 전 발명 신고서, 계약 조건 | 사내 모델만 |

- 선행기술 조사에서 **미공개 발명은 '미공개 발명(기밀)'** 을 고른다(기본값). 사내 모델이 연결되어 있지 않으면 조사하지 않고 그 이유를 알려 준다. 아이디어는 어디에도 보내지 않는다.
- 이미 출원했거나 발표한 내용만 '공개된 내용'으로 고른다.
- 사내 문서 답변 아래 **🔒 보내지 않은 문서** 가 보이면, 그 문서는 등급 때문에 AI에 보내지 않고 답했다는 뜻이다. 열람 권한은 있으니 원문을 직접 확인한다.
- **⚠️ 지시로 보이는 문장** 표시는 근거 문서 안에 "AI에게 …하라" 같은 문장이 있었다는 뜻이다(외부에서 받은 문서에 흔하다). 답변은 그 문장을 따르지 않도록 만들었고, 근거 출처에 없는 링크는 답변에서 지운다. 문서에 그런 문장이 왜 있는지는 문서 담당자에게 알린다.

## 하지 않는 것
- 신규성·진보성·침해·권리 범위 같은 법률 판단. 판단은 특허팀과 변리사에게 확인한다.
- 내 계정이 열람할 수 없는 문서는 검색 결과·답변·목록 어디에도 나오지 않는다. 필요하면 문서 소유 팀에 열람 권한을 요청한다.

## 사용량
- 계정마다 하루 LLM 요청 상한이 있다(사이드바에 표시). 넘으면 다음 날 다시 쓰거나 관리자에게 조정을 요청한다.
- 모든 요청은 감사 로그에 남는다. 입력 원문은 남기지 않고 해시만 남긴다.
