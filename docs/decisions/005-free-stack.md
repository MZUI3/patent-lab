# 005 — 운영 비용 0원: Gemini 무료 등급 + 로컬 임베딩

**맥락** — 처음에는 교육 과정의 OpenAI 호환 프록시(GMS) 키로 gpt-4o-mini / gpt-4.1과 text-embedding-3-small을 썼다. 과정이 끝나며 키가 만료됐고, 포트폴리오로 유지하려면 비용이 들지 않아야 했다.

**선택지**
1. OpenAI 선불 충전 (코드 수정 없음, 실험마다 비용)
2. LLM은 Gemini 무료 등급(OpenAI 호환 주소), 임베딩은 로컬 모델 (코드 소폭 수정, 1만 건 재색인)
3. 로컬 LLM (CPU에서 조사 1회에 7~8회 호출을 돌리기엔 너무 느림)

**결정** — 2. 코드가 OpenAI 호환 API 하나로 짜여 있어 LLM은 `.env`의 키 종류로 제공자를 정하게만 바꿨다(`GEMINI_API_KEY` → Gemini 주소). 임베딩은 `EMBEDDING_PROVIDER=local`에서 sentence-transformers `BAAI/bge-m3`(1,024차원)를 CPU로 돌린다. 모델이 바뀌므로 1만 건을 다시 색인했다(이 PC에서 약 0.7초/건).

**무료 등급에서 배운 것**
- `gemini-2.5-*`는 신규 사용자에게 제공되지 않고, `gemini-3.5-flash`는 **일일 20회** 한도라 조사 세 번이면 끝난다. 기본 모델을 둘 다 `gemini-3.5-flash-lite`(분당 15회)로 정했다.
- 429의 "40초 후 재시도"는 SDK 백오프(최대 8초)로는 못 기다린다. 프로세스 전체가 공유하는 요청 속도 제한(`LLM_RPM`, 기본 분당 10회)을 두고, 재시도 10회, 특허별 대비는 순차 호출(`COMPARE_WORKERS=1`)로 바꿨다.

**결과** — 운영 비용 0원. 기준선 평가에서 Recall@5 85%, 개시율 96%, 사례당 23초 ([평가](../eval/prior_art_eval.md)). 이전 스택과의 직접 비교 수치는 없다(유료 키가 없어 같은 평가셋으로 돌리지 못함).

**후속** — 유료 키가 생기면 같은 평가셋으로 gpt-4.1 등 상위 모델을 돌려 "모델별 판정 정확도 vs 비용" 한 줄을 요약표에 더한다.
