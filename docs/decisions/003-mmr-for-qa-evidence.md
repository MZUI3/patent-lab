# 003 — 질의응답 근거는 MMR로 고른다 (선행기술 조사 후보 생성은 재검토 중)

**맥락** — 질문이 "이 특허의 핵심 방법은 무엇이고, 스캔 체인은 왜 테스트에 쓰이나?"처럼 특허 내용과 배경 개념 두 부분으로 된 경우가 많다. 유사도 검색은 질문과 가장 가까운 청구항 청크만 5개 모아, 뒷부분(배경 개념)에 쓸 근거가 빠졌고 LLM이 엉뚱한 근거 번호를 달고 일반론을 썼다.

**선택지** — 유사도 Top-k / MMR(후보 30, λ=0.5) / 출처별 근거 수 배분.

**결정** — 질의응답 근거 검색은 MMR을 기본값으로 (`SEARCH_TYPE = "mmr"`). 같은 질문 3개에서 근거 출처 문서 수 2→5, 1→3, 2→3, 청크 간 겹침 0.649→0.338, 0.866→0.529, 0.658→0.507 ([실험](../experiments/mmr_vs_similarity.md)).

**결과·한계** — 위키 문서(각 2만 자)가 청구항보다 청크 20배 이상 많은 특허에서는 MMR도 출처 비중을 바꾸지 못했다. 출처별 근거 수 배분은 후속 과제로 남겼다 ([출처 결합 실험](../experiments/multi_source.md)).

**재검토 (2026-10-24)** — 선행기술 조사의 **후보 생성**에도 같은 MMR을 썼는데, 자동 평가에서 검색 미스 5건 중 2건이 MMR 때문이었다(정답이 유사도 2위·4위인데 바로 위의 비슷한 특허에 밀려 후보 20건에서 탈락). 질의응답 근거는 서로 다른 문서가 좋지만 선행 특허 후보는 비슷한 것끼리가 정답에 가깝다. 후보 생성만 유사도 검색(또는 λ를 높인 MMR)으로 바꾸는 실험이 다음 순서다 ([기준선 해석](../eval/prior_art_eval/baseline-flash-lite_2026-10-24.md)).
