# 009 — 자료 등급마다 보낼 수 있는 LLM을 정한다 (외부 전송 정책)

**맥락** — v2에서 운영 비용 0원을 위해 LLM을 Gemini 무료 등급으로 바꿨다([005](005-free-stack.md)). 그런데 이 서비스의 핵심 입력인 **출원 전 발명 아이디어**는 연구 조직에서 가장 민감한 자료다. Gemini API 약관(2026-03-23 시행)은 무료 등급 입력과 응답을 제품 개선에 쓰고 사람이 검토할 수 있으며, 민감·기밀 정보를 넣지 말라고 적고 있다. v2는 미공개 아이디어를 그대로 무료 등급으로 보내고 있었다. 출원 전에 발명이 새면 신규성 문제로 이어질 수 있다.

**선택지**
1. 화면에 주의 문구만 둔다 — 지켜지는지 확인할 방법이 없다
2. 모든 요청을 사내 모델로 보낸다 — CPU 로컬 LLM으로는 조사 1회에 7~8번 호출하기에 느리고([005](005-free-stack.md)), 공개 특허까지 품질을 낮출 이유가 없다
3. 자료마다 등급(공개·내부·기밀)을 두고, LLM 경로마다 받을 수 있는 최고 등급(상한)을 정해, 요청마다 보낼 자료의 최고 등급을 받을 수 있는 경로를 고른다. 받을 경로가 없으면 보내지 않는다

**결정** — 3. 판단은 정책 모듈 한 곳(`src/security/policy.py`)에서 한다.
- 경로별 기본 상한은 제공자 약관 기준이다: Gemini 무료 등급 → 공개, OpenAI API(입력을 학습에 쓰지 않는 기본 조건) → 내부, 사내 모델(`LOCAL_LLM_BASE_URL`, Ollama·vLLM 같은 OpenAI 호환 서버) → 기밀. 계약이 바뀌면(유료 등급·기업 계약) `LLM_MAX_LEVEL`로 기본 경로의 상한을 바꾼다. 데모는 사내 문서가 가상 데이터라서 `내부`로 올려 돌린다.
- **선행기술 조사**: 아이디어의 공개 여부를 묻고 기본값은 '미공개 발명(기밀)'이다(모르면 막는 쪽). 기밀을 받을 경로가 없으면 LLM을 부르기 전에 멈춘다(`SendBlocked`). 공개가 아닌 아이디어는 KIPRIS 키워드 검색도 하지 않는다 — 아이디어에서 뽑은 검색어도 외부로 나가는 자료다.
- **사내 문서 질의응답**: 근거 상위 5개의 최고 등급을 받을 경로가 있으면 그대로 보낸다. 없으면 상한을 넘는 근거를 빼고, 보낼 수 있는 근거로 5개를 채워 답한 뒤, 뺀 문서는 제목·버전만 화면에 알린다(열람 권한은 있으니 원문을 직접 보면 된다). 뺀 문서의 제목도 LLM에는 보내지 않는다 — 발명 신고서는 제목만으로도 발명 주제가 드러난다.
- **이전 대화도 보내는 자료다.** 대화 기록마다 그 답이 담은 자료의 최고 등급을 붙이고, 이번에 고른 경로의 상한을 넘는 기록은 맥락으로 보내지 않는다. 사내 모델로 기밀 문서를 근거로 답한 뒤 다음 질문이 외부 경로로 가면, 그 답이 대화 기록에 실려 함께 나가는 경로가 있었다(구현 중 코드 검토에서 발견). 등급이 없는 기록은 기밀로 본다.
- 공개 특허 기능(특허 질의응답·청구항 해설·조건 탐색)은 공개 자료만 다루므로 기본 경로를 쓴다.
- 모든 요청의 경로·보낸 자료의 최고 등급·보낸/뺀 문서 ID를 감사 로그에 남긴다. 입력은 원문 대신 해시만 남긴다 — 감사 로그가 미공개 발명이 새는 새 통로가 되지 않게.

**결과**
- 미공개 아이디어로 조사하면 아무것도 보내지 않고 이유를 알린다. 감사 로그에는 등급·해시·`blocked`만 남는다 (화면 점검).
- 단위 테스트: 기밀 문서 본문이 외부 경로 프롬프트에 들어가지 않음, 기밀을 담은 이전 대화가 외부 경로로 가는 다음 질문에 실리지 않음, 사내 모델 경로가 있으면 기밀은 그쪽으로, 상한을 넘는 근거뿐이면 LLM을 부르지 않음, 잘못된 상한 설정은 시작할 때 오류.
- 실제 질문(데모 설정 `LLM_MAX_LEVEL=내부`): "스캔 체인 진단의 상위 3개 후보 적중률은?"에 kim(반도체 테스트팀)은 기밀 발명 신고서(92.4%)를 빼고 공개 학회 초록(81.0%)으로 답을 받고, 화면에 "보내지 않은 문서: INV-2026-014 v1.2 (기밀)"이 함께 나왔다.
- 임베딩은 v2부터 로컬(bge-m3)이라 검색 단계에서는 등급과 상관없이 밖으로 나가는 것이 없다.

**한계·후속** — 질문 문장 자체의 등급은 매기지 않는다(사용자가 질문에 기밀을 적으면 그대로 나간다) → 입력 분류기나 금칙어 점검을 붙일 수 있다. 사내 모델 경로는 OpenAI 호환 서버라면 코드 수정 없이 붙지만, 이번에는 실제 사내 모델로 답변 품질을 재지 못했다.
