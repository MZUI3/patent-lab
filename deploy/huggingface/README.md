# Patent Lab

아이디어를 넣으면 가까운 한국 선행 특허를 찾아 청구항과 구성요소별로 대비하고, 사내 연구 문서는 로그인한 계정의 열람 권한 안에서만 검색합니다. 자료 등급(공개·내부·기밀)에 따라 보낼 수 있는 LLM만 쓰고, 모든 요청을 감사 로그에 남깁니다.

- 사내 문서는 데모용 **가상 데이터**입니다.
- LLM은 Gemini 무료 등급입니다. 무료 등급 약관상 입력이 서비스 개선에 쓰일 수 있으므로 **실제 미공개 발명은 입력하지 마세요.** 앱도 '미공개 발명(기밀)'으로 고른 아이디어는 보내지 않습니다.
- 계정은 운영자가 따로 안내합니다.
- 이 서비스는 특허 정보 탐색을 돕는 도구이며 법률 자문을 대신하지 않습니다.
